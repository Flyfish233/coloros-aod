# ColorOS 全天候息屏

在 ColorOS 15 上引入的**灵感接续**息屏模式支持全天候息屏，即全局 AoD。本模块强制在息屏时显示锁屏壁纸。

模块现已支持任意调暗壁纸亮度，以在夜间提供更好的体验和节省电量。调整 `SCRIM_BEHIND_ALPHA` 来控制，越小越亮。
图形化调整界面正在开发中，释出此版本用于确保代码简洁。

[下载](https://github.com/Flyfish233/coloros-aod/releases)

## 如何使用

- 在 Xposed 管理器中启用模块，然后重启系统界面即可。

- 在**壁纸与个性化**中应用**灵感接续**息屏。

  - 注意：

    锁屏样式为“艺术字”的，如 CUTE, Brilliant, Keep Moving 等，少数主题受系统影响暂时不支持：
    在你应用这些样式时，AOD 下的壁纸会替换为艺术字 Logo，因此壁纸主体不会显示。
    其他所有主题，包括“文字”样式 (如动感节奏第一个、舒缓因子等) 均支持。

## LTPO

**确保您的屏幕支持 LTPO。** 虽然所有设备都能打开 AOD，但非 LTPO 屏幕则会造成耗电问题。
AOD 屏幕显示和刷新率由系统接管，在合理的壁纸和亮度下，AOD 不会烧屏。
